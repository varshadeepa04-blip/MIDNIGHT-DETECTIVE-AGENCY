# Midnight Detective Agency

A browser-based mystery game with five case files inspired by Sherlock Holmes, Psych and Poirot. Interview suspects, collect clues, tie red string on the evidence board and name the culprit.

**Live demo:** [add your link here]

## Features
- 5 cases across 3 difficulty levels (easy, medium, hard)
- Several questions per suspect, with limited actions on harder cases
- Animated SVG scenes and suspect portraits
- Evidence board with animated red-string links
- Scoring, star ratings and progress saved in the browser
- Light and dark themes, reduced-motion support

## Tech stack
JavaScript (ES6+), HTML5, CSS3, SVG, Node.js, npm

Requires Node.js 18 or newer. No `npm install` needed.
